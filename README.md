# 🧠 Cortex-MoE: Mixture of Experts

An intelligent system that automatically routes questions to specialized AI experts.

## 🎯 Features

- **Intelligent Routing**: Automatically selects between Creative and Logic experts
- **Real-time Analytics**: Track expert usage and performance
- **Conversation Memory**: Maintains chat history during session
- **Professional UI**: Clean Streamlit interface

## 🚀 Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
